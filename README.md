# Remote File Transfer Kit

This repository is intentionally a skeleton for Codex to implement.

Read these files in order:

1. `AGENTS.md` — permanent coding rules.
2. `docs/PRODUCT_REQUIREMENTS.md` — required behavior and scope.
3. `docs/ARCHITECTURE.md` — expected design and folder boundaries.
4. `CODEX_TASKS.md` — phased implementation prompts.

Start Codex with:

> Read AGENTS.md and all files under docs/. Then implement Phase 1 from
> CODEX_TASKS.md. Do not start Phase 2. Run all required checks and summarize
> changed files, design decisions, tests, and remaining risks.
